# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. Please read it there; it is reproduced in full at that link
rather than copied here so it cannot drift from the canonical text.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

The short version, which is not a substitute for reading it: be decent to
people. Assume good faith. Criticise the code, not the person who wrote it.

## Scope

It applies in the issue tracker, in pull requests and discussions, and anywhere
someone is representing the project.

## Reporting

Report unacceptable behaviour to <6ashishs@gmail.com>. Reports are handled
privately.

This is a project maintained by one person, so a report goes to the same person
who maintains the code — worth knowing before you send one, particularly if the
report concerns me. If that makes reporting here inappropriate, GitHub's own
[abuse reporting][github] is independent of this project.

[github]: https://github.com/contact/report-abuse

I will acknowledge a report within a week.
